LanternTail — Stylized Creature Pack

A stylized creature character built for adventure, platformer and cozy exploration games. Her crystal tail glows — an emissive beacon you can recolour, pulse or switch off from a single script — and a rotted zombie variant shares the same skeleton, so one rig covers both a companion and an enemy.

Unity Asset Store Fab · Unreal Engine
31 animationsIdle, wink and squat idles; walk and hop cycles at two speeds with root-motion and in-place variants; jump, fall, land and double jump; backflip; two dodges; two attacks; hit react; sit; sleep; and a full set of gestures. Facial blinks are baked into the clips via blendshapes.
One rig, sixteen looksEight creature colourways and eight zombie colourways, each a full PBR set baked onto the same UV layout. Cycle them live in the demo — body, gear and tail glow all change together, with no hitch in the animation.
A zombie variant on the same skeletonRotted textures, matching props and its own demo scene — one rig and one animation set covers your companion and your enemy.
Swappable gearBackpack in six colourways, goggles in seven, plus shoulder straps — each a separate object with LOD1 and LOD2, toggled at runtime.
A matching prop kitNine stylized garden props and nine rotted zombie props — torii gate, trees, crystal cluster, stone platforms, ruined arch, lamppost and more — all sharing the character's art direction.
Three playable demo scenesDay, night and zombie. Every feature is on a key: animations, gear, tail glow modes, colourway cycling and an orbit camera.

Render pipelines
Built-in and URPURP verified in Unity 6 — see the note below
Render pipelines. Built for the Built-in Render Pipeline. For URP, after importing, select the materials in LanternTail_OG2/Materials and run Edit > Rendering > Materials > Convert Selected Built-in Materials to URP — all 148 materials convert cleanly, tested in Unity 6. The demo scenes' optional tail bloom uses Post Processing Stack v2, which is Built-in only; everything else — character, skins, gear, all 31 animations, props and demo scenes — works in both pipelines.
